# Game Backend Server

Высокопроизводительный backend-модуль на Go для обработки игровых матчей в реальном времени через WebSocket-соединения.

## Возможности

### Логика
* Обработка игрового процесса в реальном времени.
* Проверка корректности игровых действий.
* Валидация выстрелов.
* Контроль соблюдения игровых правил.
* Взаимодействие с клиентом через WebSockets.

### Безопасность
* 2FA-аутентификация и оддержка Google Authenticator.
* Backend-проверка одноразовых кодов.
* Валидация временных токенов безопасности.

## Архитектура хранилищ

### Redis (кэш)
* Хранение состояния активных игровых комнат.
* Защита игровых сессий от потери.
* Быстрое восстановление матчей после перезапуска сервера.

### PostgreSQL
* Учетные записи пользователей.
* Хранение ключей аутентификации.
* Долговременное хранение данных.
