# Sea Battle Backend

REST + WebSocket сервер для игры «Морской бой» на Go.

## Технологии

- **Go** (chi-router, oapi-codegen)
- **PostgreSQL** — пользователи, профили, лобби, игры, 2FA
- **sqlc** — типизированные запросы к БД
- **Goose** — миграции БД
- **WebSocket** — игровые события в реальном времени
- **JWT** — аутентификация
- **2FA** — email-коды через SMTP (опционально, без SMTP — в лог)

## Архитектура

| Компонент | Описание |
|---|---|
| `GameStore` (in-memory) | Состояние активных игр (sync.RWMutex + map) |
| PostgreSQL | Пользователи, профили, история игр, лобби |
| WebSocket | Прямое соединение для ходов и событий |

## Состояние игр

Активные игровые комнаты хранятся **в оперативной памяти** (не Redis).
При перезапуске сервера незавершённые игры теряются.
